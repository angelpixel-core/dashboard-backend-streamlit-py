# Dashboard Backend StreamLit Python


## Setup Virtual Env
```sh
python -m venv .venv
```

## Env Activation
```
source .venv/bin/activate
```


## Reload Session
```sh
exec $SHELL
```

## Setup Package Manager
```sh
brew install uv
# uv init
```

## Setup Streamlit
```sh
uv add streamlit pandas plotly
```
